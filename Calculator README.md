# Calculator Application (C++)

## Overview
A simple command-line calculator built using C++ that performs basic arithmetic operations. This project demonstrates fundamental programming concepts such as control structures, user input handling, and logical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Simple and easy-to-use interface

## Technologies Used
- C++

## How to Run
1. Download or clone this repository
2. Open the project in your compiler (VS Code / CodeBlocks)
3. Compile the file:
   g++ calculator.cpp -o calculator
4. Run:
   ./calculator
