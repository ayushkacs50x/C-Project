# Data Storage System (C++)

## Overview
A basic data storage system developed using C++ that allows storing and retrieving user data using file handling. This project demonstrates how data can be stored persistently.

## Features
- Store user data
- Retrieve stored data
- Simple data management system
- File-based storage

## Technologies Used
- C++
- File Handling

## How to Run
1. Download or clone this repository
2. Open the project in your compiler
3. Compile the file:
   g++ storage.cpp -o storage
4. Run:
   ./storage

- Learned file handling in C++
- Understood data storage concepts
- Improved structured programming skills
